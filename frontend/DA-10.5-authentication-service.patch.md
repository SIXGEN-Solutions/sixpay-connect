# Targeted frontend change — AuthenticationService

Apply these small changes to the current
`frontend/src/app/core/auth/authentication.service.ts`.

1. Add state next to the authentication-method state:

```ts
private readonly passwordChangeRequiredState =
  signal(false);

readonly passwordChangeRequired =
  this.passwordChangeRequiredState.asReadonly();
```

2. In `setCanonicalSession(...)`, after setting `activeAuthenticationMethodState`:

```ts
this.passwordChangeRequiredState.set(
  session.authenticationMethod === 'LOCAL' &&
    (session.passwordChangeRequired ?? false),
);
```

3. In `clearSession()`:

```ts
this.passwordChangeRequiredState.set(false);
```

4. In `initializeStandaloneIdentity()` before `readyState.next(true)`:

```ts
this.passwordChangeRequiredState.set(false);
```

DA-10.5 deliberately does not add the change-password screen or automatic
navigation. The frontend now understands the restricted-session state; the
dedicated UX belongs to the following frontend/password-lifecycle sub-lot.
